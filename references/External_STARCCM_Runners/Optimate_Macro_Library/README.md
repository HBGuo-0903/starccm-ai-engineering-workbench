# Optimate Macro Library

这是原始 `003_Project` 的完整 Optimate/STAR-CCM+ Java 宏库，包含设计研究宏、远程服务器连接、宏插入步骤和后处理代码。

它不是 Standalone 中的单个宏集合。项目中的 Java 文件之间存在包、工具类和 Optimate API 依赖，因此保持原始 `src`、`app`、`macros`、`optimate`、`misc` 等结构。

使用前请检查 STAR-CCM+ 版本、Optimate 类库、远程主机路径和构建配置。活动副本不包含原始测试文件和 IDE 私有文件。

同一 Jira 问题的旧实现已归档，活动副本保留 `Fix` 或 `UpdatedAgain` 版本；完整项目的 `build.xml`、`nbproject` 和 `src` 结构不得拆分。
